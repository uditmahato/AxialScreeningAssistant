{% if language == 'ne' %}"सामान्य" भनेको के हो?{% else %}What does Normal mean?{% endif %}

{% if language == 'ne' %} वर्गीकरणकर्ताले यस तस्बिरमा आफ्नो निर्णय सीमाभन्दा माथि असामान्य ढाँचा भेटेन। यसले रोग छैन भन्ने पुष्टि गर्दैन। लक्षण छन् भने चिकित्सकीय जाँच अझै आवश्यक छ। {% else %} The classifier did not detect an abnormal pattern above its decision threshold in this one image. {% if language == 'ne' %}"असामान्य" भनेको के हो?{% else %}What does Abnormal mean?{% endif %}

{% if language == 'ne' %} वर्गीकरणकर्ताले चिकित्सकीय पुनरावलोकन गर्नुपर्ने ढाँचा भेट्यो। यो कुनै रोगको निदान होइन। कारण धेरै हुन सक्छन्, र नेपालमा उपचार सम्भव संक्रमण पनि सामान्य कारण हुन्। {% else %} The classifier flagged a pattern that should be reviewed by a clinician. It is not a diagnosis of any particular disease. Many causes are possible, and in Nepal treatable infections are among the common ones. {% endif %}

{% if language == 'ne' %}मोडेलको विश्वसनीयता के हो?{% else %}What is model confidence?{% endif %}

{% if language == 'ne' %} वर्गीकरणकर्ता आफ्नो नतिजामा कति ढुक्क छ भन्ने मापन हो। यो कुनै खास रोग हुने सम्भावना होइन। उच्च विश्वसनीयता भए पनि चिकित्सकीय पुनरावलोकन आवश्यक छ। {% else %} A measure of how strongly the classifier favoured its result. It is not the probability that the patient has a specific disease. Even a high-confidence result needs clinical review. {% endif %}
