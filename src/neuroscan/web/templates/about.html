{% if language == 'ne' %}यसले के गर्छ{% else %}What it does{% endif %}

{% if language == 'ne' %} यो प्रणालीले मस्तिष्कको अक्षीय MRI तस्बिरलाई सामान्य वा असामान्य वर्गीकरण गर्छ। Grad-CAM मार्फत मोडेलले कहाँ हेर्‍यो देखाउँछ। प्रमाणित ज्ञान-भण्डारबाट सल्लाह दिन्छ। यो नेपालका जिल्ला अस्पतालहरूका लागि बनाइएको हो जहाँ रेडियोलोजिस्टको प्रतिवेदन आउन हप्तौं लाग्न सक्छ। {% else %} This system reads an axial brain MRI and calls it normal or abnormal. It shows which part of the image drove that call, using Grad-CAM. It then gives advice drawn from a verified knowledge base. It is built for district facilities in Nepal, where a radiologist's report can take weeks to arrive. {% endif %}

{% if language == 'ne' %}नेपालको सन्दर्भ{% else %}Why the Nepal context matters{% endif %}

{% if language == 'ne' %} नेपालमा न्यूरोसिस्टिसर्कोसिस र क्षयरोग (ट्युबरकुलोमा) मस्तिष्कको गाँठोका सामान्य कारण हुन्। यी स्क्यानमा क्यान्सर जस्तै देखिन्छन्, तर दुवैको उपचार सम्भव छ। त्यसैले यो प्रणालीको ज्ञान-भण्डार नेपालको वास्तविकता अनुसार तयार गरिएको छ। {% else %} In Nepal, neurocysticercosis and tuberculoma are among the most common causes of a brain lesion. On a scan, both look like tumours. Both are treatable with medicine. A system built on Western data would rank tumour first and send a family toward surgery they may not be able to afford. The knowledge base behind this system is weighted for Nepal to prevent exactly that. {% endif %}

  • Tumour type or disease severity.

  • Treatment, medication dosage or prognosis. Those decisions belong to a clinician.

{% if language == 'ne' %}हाइलाइट गरिएका भाग (Grad-CAM){% else %}Highlighted areas (Grad-CAM){% endif %}

{% if language == 'ne' %} हाइलाइट गरिएको तस्बिरले मोडेलको वर्गीकरणमा सबैभन्दा धेरै योगदान गरेका भागहरू देखाउँछ। यो मोडेलको ध्यान बुझ्ने माध्यम हो। यसले कुनै रोगको ठाउँ पहिचान गर्दैन। हाइलाइट मस्तिष्कको तन्तुमा नभई खोपडी वा तस्बिरको किनारामा छ भने नतिजामा भर नपर्नुहोस्। {% else %} The highlighted image shows the regions that contributed most strongly to the model's classification. It is a way of inspecting what the model attended to. It does not identify the location of a specific disease. If the highlight sits on the skull or the image edge rather than brain tissue, do not trust the result. {% endif %}

{% if language == 'ne' %}चिकित्सकीय सल्लाह{% else %}The clinical advisory{% endif %}

{% if language == 'ne' %} चिकित्सकीय सन्दर्भ खण्ड वर्गीकरणकर्ताबाट अलग तयार हुन्छ। यसले स्क्यानको नतिजा र समीक्षा गरिएको चिकित्सा ज्ञान-भण्डार प्रयोग गरेर सम्भावित कारण र अर्को कदम सुझाउँछ। त्यहाँ देखिने रोगका नामहरू सम्भावना हुन्, मोडेलको निदान होइनन्। {% else %} The clinical context section is generated separately from the classifier. It uses the scan result together with a reviewed medical knowledge base to suggest possible causes and next steps. Disease names that appear there are possibilities to discuss with a clinician, not diagnoses made by the model. {% endif %}
