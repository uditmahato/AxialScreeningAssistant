# Emergency Recognition - Quick Reference

A single-page reference for a health worker. **Any of the following means
immediate transfer to hospital, regardless of any scan result.**

## Go to hospital now

| Sign | Likely concern |
|---|---|
| Sudden worst-ever headache | Subarachnoid haemorrhage |
| Sudden face/arm weakness, slurred speech | Stroke |
| Seizure lasting over 5 minutes, or repeated | Status epilepticus |
| First-ever seizure | Requires investigation |
| Reducing consciousness, increasing drowsiness | Raised pressure, bleeding |
| Fever with confusion or altered behaviour | Encephalitis, meningitis |
| Head injury then deterioration | Extradural/subdural haematoma |
| One dilated pupil | Third nerve compression - herniation |
| Repeated vomiting with headache, worse on waking | Raised pressure |
| Child: morning headache, vomiting, unsteady | Posterior fossa tumour |
| Infant: bulging fontanelle, enlarging head | Hydrocephalus |
| Rapidly worsening weakness on one side | Expanding lesion |
| Sudden visual loss | Multiple serious causes |
| Neck stiffness with fever and headache | Meningitis |

## The overriding rule

**Symptoms outrank the scan.** If an automated system reports "normal" but the
patient has any sign above, the patient goes to hospital. A single axial slice
does not exclude serious disease.

## Before transfer

- Airway, breathing, circulation
- **Check blood glucose** - hypoglycaemia mimics stroke and is instantly
  reversible
- Sit the patient up to about 30 degrees if raised pressure is suspected
- Do not give anything by mouth if consciousness is reduced
- Send any imaging, films or CDs with the patient
- Send a written note of observations, timings and any treatment given
- Telephone the receiving hospital ahead where possible

## Emergency numbers in Nepal

- **Ambulance: 102**
- **Police: 100**
- **Nepal Police emergency: 100 / 1113**

Note that ambulance availability varies considerably outside urban areas, and
private vehicle transfer is frequently faster in practice. See
[[nepal-transport-and-access]].
