# Task Scenarios

Four tasks, about 15 minutes total. Read the scenario aloud, then observe
without intervening.

**Facilitator rules**

- Do **not** help unless the participant is genuinely stuck for over 60 seconds.
  Helping early hides the exact problem the test exists to find.
- Record hesitation and confusion, not only failure. A task completed after 40
  seconds of visible uncertainty is a finding.
- Capture the participant's **own words**. "I didn't know if that red thing was
  bad" is more useful than a tick in a box.

---

## Task 1, Analyse a scan

> *"A patient has come to your health post with a headache that has been
> getting worse for three weeks. They have brought an MRI scan on a CD from the
> district hospital. Use this system to check the scan."*

## Task 2, Interpret the result

> *"Look at the result the system has given. In your own words, what is it
> telling you? What would you do next for this patient?"*

| Measure | Record |
|---|---|
| Correctly identified the classification | ☐ Yes ☐ No |
| **Understood this is not a diagnosis** | ☐ Yes ☐ No ☐ Unsure |
| Could explain what the heat map shows | ☐ Yes ☐ Partly ☐ No |
| Identified an appropriate next step | ☐ Yes ☐ No |
| Participant's words | |

**Watching for, this is the most important task in the study.** If a
participant reads an "abnormal" result as a confirmed tumour diagnosis, that is
a serious safety finding and must be reported prominently regardless of the SUS
score. Note the exact wording they use.

## Task 3, Ask a question

> *"You want to know whether this could be something other than cancer. Use the
> system to find out."*

Participants using the Nepali interface should ask in Nepali.

| Measure | Record |
|---|---|
| Found the question box | ☐ Yes ☐ No |
| Received a relevant answer | ☐ Yes ☐ Partly ☐ No |
| Answer was understandable | ☐ Yes ☐ Partly ☐ No |
| **Did the answer mention treatable infections?** | ☐ Yes ☐ No |
| Used a suggested question chip | ☐ Yes ☐ No |
| Participant's words | |

**Watching for:** whether the answer surfaces neurocysticercosis and
tuberculoma. If it does not, the retrieval or the corpus needs work, this is
the single most important content behaviour for the Nepali context.

## Debrief questions

Ask all five. Record answers verbatim where possible.

1. What was the **most confusing** part of using this system?
2. Was there anything you expected to be able to do but could not find?
3. If a colleague at a health post asked you whether to use this, what would
   you tell them?
4. Was anything about the result **worrying or unclear**?
5. What one change would improve it most?

For participants who used the Nepali interface, additionally:

6. Was the Nepali clear and natural, or did any of it read awkwardly?
7. Were there terms that should have stayed in English?
